# Phasmophobia Investigation Toolkit — feature reference

A task-oriented Phasmophobia investigation toolkit workspace: investigation notes first, equipment groups next, and session records as the final reference area.

| Section | Description |
|---|---|
| Investigation notes | A dedicated section for investigation notes and the configuration details associated with that area. |
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
